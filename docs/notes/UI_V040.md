# YuzuFile v0.4.0

Minimal Home / History navigation, white background, Segoe UI, and bundled monochrome Lucide icons. Clickable dashed multi-PDF upload; removable filename/size rows; independent OCR, Markdown and Compress checkboxes. OCR and available English initially checked. Languages and compression are shown only when relevant. Process PDFs is disabled until files, operations and any required language are selected.

Per-file queue cards show status, progress and cancellation. Completed artifacts have Open File / Open Folder actions, compression sizes and percentage, and inline warnings/errors. History retains search, retry, opening and deletion controls. No settings page or sidebar was added.

All seven nonempty operation combinations are supported. OCR + Compress returns a compressed searchable PDF; adding Markdown creates both outputs. Markdown extraction precedes compression. Compression fallback preserves newly added searchable text, including when output is larger than the original scan. Existing history modes remain supported without a database schema change.

Validation: 45 unique tests passed across three isolated runs (13 UI/compression, 16 conversion, 16 storage/operations/fallback/process-lifecycle/runtime). Full single-process runs encountered Windows paging/commit exhaustion while other applications were open; isolated reruns passed. No unrelated user applications or system settings were changed. Home and combined-result screens were visually inspected using Qt offscreen rendering. Packaged validation is recorded after the Windows build completes.

Packaged validation passed with developer runtimes removed from PATH: bundled language discovery, digital Markdown, scanned OCR plus Markdown, all three compression levels, and the actual Home workflow with all operations selected. Frozen GUI completed successfully and exposed two outputs (Markdown and compressed searchable PDF). Final frozen UI screenshot inspected; portable ZIP CRC and Lucide license/source entries verified.
